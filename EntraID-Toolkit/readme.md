# 🚀 Microsoft Graph PowerShell Scripts

A collection of PowerShell automation scripts built using the **Microsoft Graph PowerShell SDK** to simplify Microsoft Entra ID (Azure AD) administration and reporting.

These scripts are designed to automate common administrative tasks, generate reports, and demonstrate practical PowerShell scripting skills for Microsoft 365 environments.

---

## 📌 Project Overview

As a **Microsoft 365 / Cloud Engineer**, I regularly use PowerShell to automate repetitive administrative tasks.

This repository documents my journey of mastering PowerShell through real-world automation projects instead of isolated code snippets. Each script is written with readability, object-oriented PowerShell practices, and automation in mind.

# ▶️ Requirements

Install Microsoft Graph PowerShell SDK

```powershell
Install-Module Microsoft.Graph -Scope CurrentUser
```

Connect to Microsoft Graph

```powershell
Connect-MgGraph -Scopes "User.Read.All","Organization.Read.All"
```
